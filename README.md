Technologies used:

o	PHP
o	HTML
o	CSS
o	Javascript
o	DataBase(Mysql)

Features:
o	Browse Movies: Users can view a list of available movies.
o	Search and Filter: Users can search for movies based on title, date, location, genre and movie ID.
o	Movie Details: Users can view detailed information about a specific movie, including title, director, description, genre, date, location, total seats, available seats, and price of ticket.
o	Booking Tickets: Users can book tickets for a movie by specifying the movie ID, quantity of tickets, and total price.
o	Booking History: Users can view their booking history, which includes details of movies they have booked, such as title, director, description, genre, date, location, booked tickets, and total price.
o	Add/Delete/Update Movies: Admin users can add new movies, delete existing movies, and update movie information.

Objectives for a Movie Ticket Booking System

  Customer can:
1.	Sign up / log in to their account.
2.	Search for movies by:
o	Title
o	Genre
o	Language
o	Release date
3.	View detailed information about movies, including:
o	Synopsis
o	Cast and crew
o	Show timings
4.	Book tickets for a specific showtime, selecting:
o	Number of seats
o	Seat type (e.g., regular, premium, balcony).
5.	View their booking history, filtering by:
o	Upcoming bookings
o	Past bookings
o	All bookings
6.	Cancel bookings within a specified cancellation period.
7.	Check ticket prices before booking.

  Admin can:
1.	Log in to the admin dashboard.
2.	Manage movies:
o	Add, update, or delete movies.
o	Filter movies by genre, language, or release date.
3.	Manage showtimes:
o	Add, update, or delete showtimes.
o	Assign movies to specific screens and time slots.
4.	Manage bookings:
o	View all bookings.
o	Search bookings by customer ID or movie title.
o	Filter bookings by:
	Movie
	Show date/time
	Booking status (e.g., confirmed, canceled).
5.	Manage customers:
o	Add, search, modify, or delete customer profiles.
o	Filter customers by membership level (e.g., regular, premium).
o	View all bookings and cancellations associated with a customer.
6.	Set and manage ticket pricing:
o	Define prices based on seat type and screen type.
o	Adjust prices dynamically based on demand or time.
7.	Generate reports:
o	Daily/weekly revenue reports.
o	Booking trends by genre, language, or customer demographics.
o	Cancellations and refund analysis.
